How to read them:
- They are design files, not pages of this site: they do not render on their own (they need the
  canvas runtime). Read them as source: the structure, the texts, the inline styles (colours, sizes,
  spacing) and, in `desktop.html`, the offers list in the script at the end.
- `/_blob/…` addresses are the canvas's uploaded images. Use the matching image already in
  `public/images/` (hero, services, locations, logos); never download or link a `/_blob/` address.
- Text in brackets (`[TELEFON]`, `[RADNO VRIJEME]`, `[OCJENA]`) is a placeholder, not a value.
- Where the brief's **Mockup** section or **Decided** says something else, the brief wins (e.g. the
  centre names and which centre is bookable, the hero video on mobile).
